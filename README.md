# Мебель 3D

Новый Android-проект конструктора интерьеров и мебели.

Репозиторий предназначен для новой версии приложения по утверждённому техническому заданию. Старый проект `Mebel-3d` не используется.

## Цель
Подготовить цельное Android-приложение с горизонтальным светлым интерфейсом, редактируемой 3D-комнатой, планировкой мебели и инженерных элементов, сохранением проектов и установочным APK.

## Текущий статус
Репозиторий создан. Исходный код приложения и сборочная конфигурация ещё не загружены.
