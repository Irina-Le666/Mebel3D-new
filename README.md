# Мебель 3D — новый проект

Android-приложение для точного планирования жилых помещений и расстановки мебели. Проект ведётся отдельно в репозитории `Irina-Le666/Mebel3D-new`.

## Обязательные принципы
- Только новый проект; старый `Mebel-3d` не используется и не изменяется.
- Светлый горизонтальный интерфейс: большая рабочая область, компактная панель инструментов слева.
- Единая геометрическая модель — источник данных для плана, 3D-сцены, размеров и настенных проекций.
- Поддержка разных жилых помещений, мебели, дверей, окон, инженерных элементов, фотофиксации и отделки.
- Фото не считаются автоматическим точным 3D-сканированием: используются ручная привязка, калибровка и проверяемый перенос отметок.
- Производственное направление исключено: карты раскроя, кромление, спецификации крепежа, производственные карты и расчёты изготовления не входят в цель приложения.
- APK — только итог готового и проверенного приложения, а не промежуточная сборка сырого прототипа.

## Реализованные интеграционные блоки в локальной рабочей копии
- Модель помещений, мебели, сборок, проёмов и инженерных элементов с геометрической валидацией.
- Редактирование мебели и параметрических деталей, выбор и преобразования на сцене.
- Планирование расстановки с проверкой коллизий, проходов и зон доступа.
- План и четыре схематических вида стен на общей системе координат с 3D-сценой.
- Фото помещения: импорт/съёмка, калибровка стены, многокадровое покрытие, разметка и безопасный перенос/синхронизация элементов.
- Отделка стен, пола и потолка, независимая отделка каждой стены и настройки визуального освещения.
- Сохранение проектов, проверка данных, история изменений и варианты интерьера.
- Android Compose-интерфейс с разделами помещений, планировки, мебели, конструктора, материалов, инженерии, схем и фотографий.

## Следующие обязательные этапы
1. Загрузить исходники именно этой рабочей копии в `Mebel3D-new`.
2. Запустить полную Kotlin-регрессию в CI и исправить все найденные ошибки.
3. Выполнить Android unit tests и полную Compose/Gradle-компиляцию.
4. Проверить основные сценарии на Android-устройстве: создание комнаты, мебель, выделение/редактирование, двери/окна/инженерия, фото, сохранение/открытие, план/3D.
5. Только после устранения блокирующих дефектов собрать и проверить установочный APK.
