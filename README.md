# Мебель 3D — новый Android-проект

Android-приложение для точного планирования жилых помещений и расстановки мебели. Основной репозиторий: `Irina-Le666/Mebel3D-new`.

## Обязательные принципы

- Разрабатывается только новый проект; старый `Mebel-3d` не используется и не изменяется.
- Светлый горизонтальный интерфейс: большая рабочая область комнаты и компактная панель слева.
- Единая геометрическая модель служит источником данных для плана, 3D-проекции и четырёх видов стен.
- Поддерживаются жилые помещения, мебель, проёмы, инженерные элементы, фотофиксация и отделка.
- Фото не считаются автоматическим точным 3D-сканированием: используются ручная привязка, калибровка и проверяемый перенос отметок.
- Производственное направление исключено: раскрой, кромление, крепёжные спецификации и производственные карты не разрабатываются.
- Debug APK уже собран для проверки; финальная релизная сборка допускается только после приёмки на Android-устройстве.

## Реализованные интеграционные блоки

- Геометрическая модель комнаты, мебели, параметрических сборок, проёмов и инженерных элементов.
- Каталог мебели, выбор и редактирование предметов и отдельных деталей, перемещение, поворот, изменение размеров.
- Проверки пересечений, проходов, доступа к дверям и инженерным точкам; предварительная умная расстановка.
- Светлый горизонтальный Android Compose UI, 2D-план и изометрическая 3D-проекция с вращением и масштабированием.
- План и четыре схематических вида стен на общей системе координат с 3D-сценой.
- Фото с камеры/из галереи, калибровка стены, покрытие нескольких фото, разметка и синхронизируемый перенос элементов.
- Отделка пола, потолка и отдельных стен, варианты интерьера.
- Сохранение/открытие, импорт/экспорт проекта, история изменений и проверка целостности данных.
