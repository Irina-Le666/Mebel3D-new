# Сборка и получение APK «Мебель 3D»

## Единственный поддерживаемый путь сборки

Проект использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Gradle 8.9, JDK 17 и Android SDK Platform 35. Сборка должна выполняться в чистой среде Android CI; ручная подмена версий инструментов не считается проверенной сборкой.

В `.github/workflows/android.yml` настроены:

1. полный прогон 70 core smoke-наборов;
2. статическая проверка интеграции `scripts/check-release-readiness.sh`;
3. Android `testDebugUnitTest`;
4. Android `assembleDebug`;
5. публикация APK вместе с SHA-256 и информацией о сборке в одном GitHub Actions artifact.

Workflow запускается при push / pull request и вручную через `workflow_dispatch`. Артефакт имеет имя `Mebel3D-debug-APK-<commit>` и хранится 30 дней.

## Ручная сборка в подготовленной Android-среде

Из корня проекта:

```bash
./scripts/check-release-readiness.sh
./scripts/check-core.sh
gradle --no-daemon :android:app:testDebugUnitTest
gradle --no-daemon :android:app:assembleDebug
```

APK появляется по адресу:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Это debug APK, подписанный debug-ключом Android Gradle Plugin, пригодный для самостоятельной установки на устройство. Это не релизная публикационная подпись Google Play.

## Ограничения подтверждения

`check-release-readiness.sh` проверяет структуру проекта и связность CI, но не подменяет компиляцию Android UI. Готовность APK подтверждается только успешными `testDebugUnitTest` и `assembleDebug`, наличием APK и проверкой SHA-256. Проверка установки и запуска на физическом телефоне должна быть отмечена отдельно; её нельзя выводить из успешной сборки.

## Требования к репозиторию

Новый проект должен находиться в отдельном репозитории. Не помещать его поверх старого проекта и не использовать старый репозиторий как источник Android-кода. Пока отдельный репозиторий с этой версией исходников не подключён к CI, workflow описывает воспроизводимый путь сборки, но сам APK ещё не создан.

## Функциональный объём чертежей

В приложении остаются только наглядные интерьерные схемы: план комнаты, четыре вида стен, мебель, проёмы и инженерные точки. Пакет формализованных листов и производственные чертежи не входят в цель проекта.
