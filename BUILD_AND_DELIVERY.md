## Воспроизводимый CI-путь

В `.github/workflows/android.yml` настроены JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9, core regression, Android unit tests, debug APK assembly и публикация APK с SHA-256. Артефакт хранится 30 дней.

## Локальная сборка

Для локального запуска нужны JDK 17, Gradle 8.9, Android SDK Platform 35 и Build Tools 35.0.0. Gradle Wrapper в репозитории отсутствует; локальный gate проверяет установленный Gradle и SDK.

В текущей среде аудита Gradle, Android SDK и JDK 17 отсутствуют (доступна Java 21), поэтому локальную Android-сборку повторить нельзя. Это не отменяет успешную CI-сборку, но ограничивает независимое воспроизведение в этой среде.

## Что ещё не подтверждено

- Установка и запуск APK на физическом Android-телефоне.
- Сквозная приёмка основных пользовательских сценариев на реальном устройстве.
- Релизная подпись APK.

Успешная CI-сборка не доказывает успешную установку на конкретном телефоне. Финальную релизную сборку готовить только после проверки на устройстве и исправления найденных дефектов.

## Границы продукта

Остаются только интерьерные схемы: план комнаты, четыре вида стен, мебель, проёмы и инженерные точки. Производственные чертежи, раскрой, кромление и спецификации изготовления исключены.
