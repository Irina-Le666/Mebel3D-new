# Фоторазметка → геометрия стены

## Система координат

- Координаты фотографии: начало в левом верхнем углу; `x` растёт вправо, `y` — вниз.
- Координаты помещения: высота `z` отсчитывается от пола вверх.
- Масштаб вычисляется по известной длине стены и числу пикселей на этой длине (`мм/px`).
- Для текущего переноса предполагается фронтальная фотография всей стены от пола до потолка. Перспективное выпрямление и автоматическое определение плоскости стены не выполняются.

## Привязка к четырём стенам

- `NORTH`: плоскость `Y = 0`, смещение по стене идёт вдоль `X` от 0 до ширины комнаты.
- `SOUTH`: плоскость `Y = room.depthMm`, смещение идёт вдоль `X`.
- `EAST`: плоскость `X = room.widthMm`, смещение идёт вдоль `Y` от 0 до глубины комнаты.
- `WEST`: плоскость `X = 0`, смещение идёт вдоль `Y`.

Инженерная отметка с указанной стеной должна лежать именно на соответствующей граничной плоскости. Для напольных/внутренних точек `wallSide` остаётся `null`. При выборе стены в редакторе координата граничной плоскости подставляется автоматически; продольная координата и высота остаются редактируемыми. Перед сохранением координаты нормализуются через `GeometryEngine.wallPosition()`.

Отметки с одинаковым ID между проёмами и инженерными элементами отклоняются: ID служит стабильным ключом выбора, редактирования и переноса фоторазметки. Проверки размеров диаметра ограничены общим диапазоном параметрических значений. Пиксельные суммы `x + width` и `y + height` рассчитываются в `Long`, чтобы повреждённая разметка не могла переполнить `Int`.

## Вертикальное преобразование

Для отметки с верхней координатой `y` и высотой `h`:

- `topFromFloor = roomHeight - y * mmPerPx`
- `bottomFromFloor = roomHeight - (y + h) * mmPerPx`

Для окна:

- `sillHeight = bottomFromFloor`
- `openingHeight = topFromFloor - bottomFromFloor`

Для двери:

- `sillHeight = 0`
- `openingHeight = topFromFloor`

Отметка отклоняется, если верхняя или нижняя граница не укладывается в физическую высоту помещения. Для двери нижняя граница должна касаться пола с допуском 50 мм. Это защищает геометрию от неверных проёмов, созданных по обрезанной или неправильно откалиброванной фотографии.

## Проверки

`PhotoWallTransferSmoke` и `PhotoWallSideTransferSmoke` проверяют:
- корректную высоту двери от пола до верхней границы отметки;
- высоту подоконника и высоту окна;
- вертикальную высоту инженерной точки;
- отказ от отметки, выходящей за высоту помещения;
- повторный перенос без создания дубликатов;
- правильные координаты инженерных отметок для всех четырёх стен.

## Добавление фотографии с камеры Android

В разделе «Фото помещения» доступны два источника: съёмка камерой и выбор существующего изображения. Для съёмки используется Android `TakePicture` с временным URI от `FileProvider`; приложению не требуется запрашивать широкое разрешение на доступ к камере или ко всей галерее. После возврата из камеры файл копируется в приватную папку текущего проекта `files/photo-assets/<projectId>/captured/`, а в модели хранится локальный URI. Поэтому снимок остаётся доступен после перезапуска приложения и включается в переносимый ZIP-пакет проекта. Временный файл из cache удаляется после копирования.

Это именно захват фотографии, а не автоматическое построение 3D-сетки по фотографии. Для получения размеров и переноса проёмов/инженерии по-прежнему используется ручная разметка и калибровка.
